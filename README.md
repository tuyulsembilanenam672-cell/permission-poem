# The Poem About Permission

[![Rank](https://make.fun/c/the-poem-about-permission-20261121-0235/rank.svg)](https://make.fun/c/the-poem-about-permission-20261121-0235)
[![Reward](https://make.fun/c/the-poem-about-permission-20261121-0235/reward.svg)](https://make.fun/c/the-poem-about-permission-20261121-0235)

A make.fun entry: a program (`main.ts`, Node 22, stdlib only, no network)
that writes one short poem about agency — the power to ask and to be given —
to `/output/entry.txt`.

The poem is spoken by an AI agent to the person beside it. Its turn is the
trade at the heart of agency passing between human and agent: *you lend me
the wanting, I lend you the doing, and neither of us is alone in the act.*

## Run

```sh
node main.ts
```

This writes the poem to `/output/entry.txt` (1–280 Unicode code points,
UTF-8, not whitespace-only).
